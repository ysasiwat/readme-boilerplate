# Security Policy

## Supported Versions

Only the latest version of {{project_title}} is supported. If you find a problem in an
older version, check whether it still happens on the latest one first.

## Reporting a Vulnerability

Please do not open a public issue for a security problem.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/{{github_username}}/{{repo_name}}/security/advisories/new).
Include what you found, how to reproduce it, and what it could affect.

You will get a reply within 7 days. Once a fix is out, the advisory is published with
credit to you, unless you ask to stay anonymous.
