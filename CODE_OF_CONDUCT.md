# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By taking part in this project — issues, pull requests, discussions — you agree to it.

## Reporting

If someone's behavior breaks the code of conduct, report it privately to the
maintainer, [@ysasiwat](https://github.com/ysasiwat), using the contact details on that
profile. Reports are kept confidential.
