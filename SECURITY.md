# Security Policy

## Supported Versions

Only the latest version on `master` is supported. If you find a problem in an older
version, check whether it still happens on the latest one first.

## Reporting a Vulnerability

Please do not open a public issue for a security problem.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ysasiwat/readme-boilerplate/security/advisories/new).
Include what you found, how to reproduce it, and what it could affect.

You will get a reply as soon as the maintainer can look at it. Once a fix is out, the advisory is published with
credit to you, unless you ask to stay anonymous.
