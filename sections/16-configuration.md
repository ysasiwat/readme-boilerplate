## Configuration

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `port` | number | `3000` | Port the server listens on |
| `debug` | boolean | `false` | Print debug logs |
| `timeout` | number | `30000` | Request timeout in milliseconds |

### Environment Variables

```sh
APP_PORT=8080
APP_DEBUG=true
```
