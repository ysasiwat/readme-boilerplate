## Getting Started

Instructions for getting a local copy up and running.

### Prerequisites

* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/github_username/repo_name.git
   ```
2. Install packages
   ```sh
   npm install
   ```
3. Configure `config.js`
   ```js
   const API_KEY = 'ENTER YOUR API';
   ```
